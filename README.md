# Транслятор C → Python

Учебный транслятор, который переводит подмножество языка C в исполняемый Python-код.
Проект включает полный конвейер обработки исходного текста (лексер → парсер → семантический анализ → генератор кода), графический интерфейс на `tkinter`, набор C-примеров и тесты.

## Возможности

### Лексический анализ

- Ключевые слова: `int`, `char`, `float`, `double`, `void`, `if`, `else`, `while`, `for`,
  `do`, `return`, `break`, `continue`, `switch`, `case`, `default`, `const`, `true`, `false`,
  `short`, `long`, `unsigned`, `signed`.
- Идентификаторы, макроподобные имена (`MAX_SIZE`), числа (десятичные, шестнадцатеричные,
  с плавающей точкой), строковые и символьные литералы.
- Комментарии `// ...` и `/* ... */` (переносятся в Python как комментарии).
- Операторы: арифметические, сравнения, логические, побитовые, сдвиги, составное
  присваивание (`+=`, `-=`, `*=`, `/=`, `%=`), тернарный `?:`, унарные `!`, `-`, `+`, `~`,
  инкремент/декремент `++`/`--`.
- Точная позиция каждого токена (строка и столбец).

### Синтаксический анализ

Поддерживаются:

- объявления переменных, в том числе нескольких в одном операторе (`int a = 1, b = 2;`);
- массивы, включая многомерные (`int a[2][3];`), с инициализаторами `{...}`
  (вложенными и плоскими) и доступом по индексам `a[i][j]`;
- квалификаторы типов `short`, `long`, `unsigned`, `signed` (нормализуются к базовому типу);
- `const`-переменные;
- ветвления `if` / `else`;
- циклы `while`, `do ... while`, `for`;
- `switch` / `case` / `default`;
- `break`, `continue`, `return`;
- определения функций с параметрами и рекурсией;
- вызовы функций, в том числе объявленных ниже точки вызова;
- выражения с корректным приоритетом операций (рекурсивный спуск);
- директивы препроцессора `#include`, `#define`, `#ifdef`, `#ifndef`, `#else`, `#endif`.

### Семантический анализ

- Таблица символов с глобальной и локальными областями видимости.
- Проверка повторных объявлений переменных и функций.
- Проверка использования необъявленных идентификаторов и функций.
- Проверка количества аргументов при вызове функции.
- Проверка индексации массивов: число индексов не должно превышать число измерений.
- Запрет изменения `const`-переменных и элементов `const`-массивов.
- Проверка `break` / `continue` только внутри циклов и `switch`.
- Проверки `return`: значение запрещено в `void`-функции и обязательно в не-`void`.

### Генерация кода

- Массивы → вложенные списки Python: без инициализатора заполняются нулями
  (`[[0] * n for _ in range(m)]`), инициализатор `{...}` переносится в литерал списка,
  незаполненные элементы дополняются нулями; доступ `a[i][j]` сохраняется.
- `printf(...)` → `print(...)` с формированием f-строки (поддерживаются спецификаторы
  `%d`, `%i`, `%s`, `%c`, `%f`, `%e`, `%g`, `%%`).
- `#define` с числовым, строковым или флаговым значением → константа Python.
- `#include <math.h>` → `import math`; стандартные заголовки (`stdio.h`, `stdlib.h`,
  `string.h`, `ctype.h`, `stdbool.h`) не импортируются; неизвестный заголовок отмечается
  комментарием `# TODO`.
- `for` с типовой формой `for (i = a; i < b; i++)` оптимизируется в `for i in range(...)`,
  остальные формы разворачиваются в `while`.
- `do ... while` → `while True` с условием выхода через `break`.
- `switch` → цепочка `if` / `elif` / `else`.
- Наличие `main` добавляет точку входа `if __name__ == "__main__": main()`.

### Графический интерфейс

- Два поля: исходный C-код и сгенерированный Python-код.
- Кнопки «Транслировать», «Загрузить .c», «Сохранить .py».
- Вкладки «Ошибки», «Токены», «AST», «Этапы / Отладка».
- Подсветка ошибок с указанием этапа, кода, сообщения, строки и столбца.
- Горячая клавиша `Ctrl+Enter` для запуска трансляции.
- Контекстное меню и стандартные сочетания клавиш для копирования/вставки.

## Как это работает

```text
исходный C-код
      │
      ▼
   Lexer          посимвольная разбивка на токены (src/lexer.py)
      │
      ▼
   Parser         построение AST методом рекурсивного спуска (src/parser.py)
      │
      ▼
SemanticAnalyzer  таблица символов и проверки (src/semantic.py)
      │
      ▼
 CodeGenerator    генерация Python-кода (src/codegen.py)
      │
      ▼
 TranslationResult  success / python_code / errors / tokens / ast
```

Точка входа конвейера — функция `translate()` в [`src/translator.py`](src/translator.py).
Она перехватывает `TranslationException` и возвращает результат с описанием ошибки,
а непредвиденные исключения оборачивает в ошибку `E_INTERNAL`.

## Требования

- Python 3.10 или новее.
- `tkinter` (входит в стандартную поставку Python для Windows; в Linux может потребоваться
  пакет `python3-tk`).
- `pytest` — только для запуска тестов.

Зависимостей времени выполнения нет: используются только модули стандартной библиотеки.

## Запуск GUI

```bash
python main.py
```

Порядок работы:

1. Вставьте C-код в левое поле или нажмите «Загрузить .c».
2. Нажмите «Транслировать» (или `Ctrl+Enter`).
3. Результат появится в правом поле; ошибки, токены, AST и отладочная информация — на нижних вкладках.
4. Нажмите «Сохранить .py», чтобы записать результат в файл.

## Использование как библиотеки

```python
from src.translator import translate

source = """
#include <stdio.h>

int main() {
    printf("Hello, %s!\\n", "world");
    return 0;
}
"""

result = translate(source, debug=True)

if result.success:
    print(result.python_code)
else:
    for error in result.errors:
        print(error)
```

`translate(source, debug=False)` возвращает `TranslationResult`:

| Поле | Тип | Описание |
| --- | --- | --- |
| `success` | `bool` | Успешна ли трансляция |
| `python_code` | `str \| None` | Сгенерированный Python-код |
| `errors` | `list[TranslationError]` | Список ошибок (обычно одна) |
| `tokens` | `list[Token] \| None` | Токены (только при `debug=True`) |
| `ast` | `Program \| None` | AST (только при `debug=True`) |

Каждая ошибка `TranslationError` содержит `stage`, `code`, `message`, `line`, `col`
и печатается в формате:

```text
[parser] E_PARSE_EXPECTED: Ожидалось ;, получено '}' (строка 4, столбец 15)
```

## Пример трансляции

Входной файл:

```c
#include <stdio.h>

int square(int n) {
    return n * n;
}

int main() {
    for (int i = 1; i <= 3; i++) {
        printf("%d^2 = %d\n", i, square(i));
    }
    return 0;
}
```

Результат:

```python
def square(n):
    return n * n


def main():
    for i in range(1, (3) + 1):
        print(f"{i}^2 = {square(i)}\n")
    return 0


if __name__ == "__main__":
    main()
```

## Коды ошибок

### Лексер

| Код | Причина |
| --- | --- |
| `E_LEX_INVALID_CHAR` | Недопустимый символ во входном тексте |

### Парсер

| Код | Причина |
| --- | --- |
| `E_PARSE_UNEXPECTED_TOKEN` | Неожиданная категория токена |
| `E_PARSE_EXPECTED` | Ожидался конкретный токен (например, `;` или `)`) |
| `E_PARSE_INCLUDE` | Некорректная директива `#include` |
| `E_PARSE_DEFINE` | Некорректная директива `#define` |
| `E_PARSE_FUNC_RET` | Не указан тип возвращаемого значения функции |
| `E_PARSE_FUNC_NAME` | Ожидалось имя функции |
| `E_PARSE_PARAM_TYPE` | Не указан тип параметра функции |
| `E_PARSE_DECL_TYPE` | Не указан тип переменной |
| `E_PARSE_IFDEF` | Ошибка в блоке `#ifdef` / `#ifndef` (нет имени или `#endif`) |
| `E_PARSE_DOWHILE` | После тела `do` отсутствует `while` |
| `E_PARSE_SWITCH` | В `switch` ожидался `case` или `default` |
| `E_PARSE_PRIMARY` | Неожиданный токен в первичном выражении |

### Семантика

| Код | Причина |
| --- | --- |
| `E_SEM_REDECLARED` | Повторное объявление переменной или функции |
| `E_SEM_UNDECLARED` | Использование необъявленного идентификатора |
| `E_SEM_FUNC_UNDECLARED` | Вызов необъявленной функции |
| `E_SEM_ARGS_COUNT` | Неверное количество аргументов функции |
| `E_SEM_ARRAY_INDEX` | Индексация не-массива или слишком много индексов |
| `E_SEM_LVALUE` | Слева от присваивания не идентификатор и не элемент массива |
| `E_SEM_CONST_MODIFY` | Попытка изменить `const`-переменную |
| `E_SEM_LOOP_CTRL` | `break` / `continue` вне цикла или `switch` |
| `E_SEM_RET_VOID` | Возврат значения из `void`-функции |
| `E_SEM_RET_MISSING` | Отсутствует возвращаемое значение в не-`void` функции |
| `E_SEM_UNKNOWN_STMT` | Неизвестный тип инструкции |
| `E_SEM_UNKNOWN_EXPR` | Неизвестный тип выражения |

### Генерация и внутренние ошибки

| Код | Причина |
| --- | --- |
| `E_CG_UNKNOWN_STMT` | Генерация для инструкции не реализована |
| `E_CG_UNKNOWN_EXPR` | Генерация для выражения не реализована |
| `E_INTERNAL` | Непредвиденная внутренняя ошибка |

## Ограничения

транслятор рассчитан на учебное подмножество C и не является полноценным компилятором.

- Не поддерживаются указатели, структуры, объединения, перечисления, `typedef`, `goto`, `sizeof`, приведение типов и прототипы функций.
- Для массивов не выполняется проверка выхода за границы: ответственность за корректные
  индексы лежит на исходной программе.
- `scanf` не переводится: в месте вызова генерируется комментарий
  `# TODO: scanf не поддерживается транслятором`.
- Макросы `#define` подставляются только как простые литеральные константы; макросы
  с параметрами и сложные выражения не раскрываются.
- На верхнем уровне блоки `#ifdef` / `#ifndef` пропускаются целиком; условная компиляция
  выбирается только внутри функций.
- `switch` не воспроизводит C-семантику проваливания (`fallthrough`): каждая ветка
  независима, завершающий `break` отбрасывается.
- Форматирование `printf` упрощено: ширина, точность и флаги не переносятся в f-строку.
- Целочисленная арифметика C (переполнение, беззнаковые типы, целочисленное деление)
  не эмулируется — используется семантика Python.
- `main` с параметрами командной строки не поддерживается: генерируется вызов `main()`.
- Аннотации типов в Python-код не добавляются.
